Menu Application: Dish & Chef Filtering

A Spring Boot web application for browsing a restaurant menu. It lists dishes and their chefs, and lets you filter the dishes by chef, 
delete & add chefs as well as dishes.

Built as a university web lab project.

Features
- View the full list of dishes
- See which chef prepares each dish
- Filter dishes by chef
- Delete/Add Dishes
- Delete/Add Chefs
- Like/Dislike a specific dish
  
Tech stack
-Java
-Spring Boot
-H2
